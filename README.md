# Shooting Game

## Overview
A First Person Shooter game with randomly spawning enemies and items

## Installation and Usage
Download the most recent release, unzip and run Shooting Game.exe

## Features
- Various weapons for the player to use
- Regularly spawning enemies and items at random places on the map
- Health systems for the player and enemies
- Healing and reloading weapons
- Controls in the start screen

## Technologies
- Unity
- C#
